
# Todo List

## Live Demo: 
https://frozerated.github.io/todo-lists/

## Features

- Deadline Indicators - colored border on the task card if the deadline is overdue or less than 24 hours away.

- Time Remaining - Displays the hours remaining until a task's deadline when the deadline is less than 24 hours.

- Session Storage - Saves projects and tasks in the browser's sessionStorage during the current tab session.

- Custom Project Colors - Lets you assign colors to project folders for easier identification.

- Priority Colors - Uses different colors to distinguish task priorities.
